# AI 智能问答助手 PC 视觉版

该目录是从黑白功能原型复制出的独立高保真项目，原始功能原型未在此目录修改。

视觉切图及替换说明见 `assets/README.md`。

## 打开方式

直接双击 `index.html`，使用桌面浏览器打开即可。原型为单文件、无外部依赖，不需要安装前端环境。

如果浏览器限制直接打开本地文件，可在本目录运行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4173/`。

## 建议演示尺寸

- 基准窗口：1440 × 900
- 投屏尺寸：1920 × 1080

## 建议演示路径

1. 从欢迎消息点击“了解风险特征”，查看助手回复的 7 种特征。
2. 点击“调整规则参数”，演示救助类型与监管药品类目的添加、改名和删除。
3. 切换到“规则参数”，演示规则1–5的阈值调整。
4. 点击“组合风险筛查”，查看复合风险、核心风险两种方式。
5. 在助手回复的自定义卡片中勾选特征并调整参数。
6. 执行模拟检索，查看助手返回的人员列表和命中特征。
7. 在结果消息中演示空结果状态。
8. 点击顶部“复位演示”，恢复初始状态。

## 原型边界

- 使用虚构人员和模拟结果。
- 不连接真实医保数据。
- 不包含后端、数据库、模型或规则引擎。
- 页面结果只用于原型演示，不构成违法犯罪定性依据。
